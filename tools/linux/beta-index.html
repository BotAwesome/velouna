Pop!_OS / Ubuntu (.deb)

cd ~/Downloads
sudo apt install ./__DEB__

Alles ist dabei: mpv, FFmpeg, ffprobe und yt-dlp. Danach steht Velour im App-Menü. Entfernen: sudo apt remove velour

Andere Distributionen (.tar.gz)

tar xzf __TGZ__
cd __TGZDIR__
./install.sh

Installiert nach ~/.local/share/velour, kein Root nötig. Entfernen: ./uninstall.sh

Was testen?

  • Startet das Fenster (Wayland/COSMIC und X11)? Ziehen, Größe ändern, Maximieren
  • Video abspielen – Bild, Ton, Hardware-Dekodierung, Vorschaubilder im Seek-Bar (braucht ffmpeg)
  • Datei- und Ordnerdialog, „Öffnen mit“ aus dem Dateimanager, Drag & Drop
  • Plex-Anmeldung (wird im Schlüsselbund gespeichert), TV, Radio
  • „Im Dateimanager zeigen“, Links öffnen

Wenn etwas nicht geht: im Terminal velour starten und die Ausgabe schicken – oder die Datei ~/.cache/velour/velour.log.
