Speed

Half a second from double‑click to picture.

No splash screen, no library scan, no waiting. The file goes to mpv the moment the window can show a picture, decoded on the graphics card. Even when Velouna wasn't running.

  • Cold start to the first frame in about 0.55 s, to the first note of a song in 0.4 s
  • Already open? The next file plays in 0.1 to 0.6 s, in the same window
  • Hardware decoding on the graphics card, also for 4K HEVC

Player

A thick seek bar. Thin everything else.

The picture gets the screen. Controls stay slim until you need them, and the seek bar is big enough to hit the first time, with a preview of where you are going.

  • Preview thumbnails and chapter marks on the seek bar, optionally a waveform
  • Resume where you stopped, speed, A-B repeat and a sleep timer that fades out
  • 10-band equalizer and a subtitle style editor
  • Picture-in-picture and a queue you can reorder

Hover the seek bar: preview, chapter name and time.

Music

Music you can see.

Play a song and Velouna listens to all of it first: beats, kicks, snares, build-ups and drops. So the visualizer knows what is coming. The picture gathers during a build-up and breaks open on the drop.

  • The Velounizer with Ink, Aurora and Contour, each with palettes and its own sliders
  • Same seed, same picture, and after seeking it is right where the song is
  • A now-playing page with cover and queue when the visualizer is off
  • Drawn on the graphics card, analysed once per song and cached

Plugins

Make it yours.

Visualizers come as plugins, and anyone can write one: a shader and, if you like, a few lines of Lua. Put it in a repo of your own, and others add it with its link.

  • A catalog with the official repo built in: tick, install, done
  • Any repo by its link, or just one plugin from it
  • Signed repos: if a repo's key ever changes, Velouna stops its updates and warns you
  • Reload shows your changes the moment you save

glow/draw.glsl
void main() {
    vec2 p = (px() - F_res.xy * 0.5) / F_time.w;
    float kick = F_pulse.x;   // jumps on a kick
    float r = 0.18 + 0.06 * kick;
    float glow = exp(-max(length(p) - r, 0.0) * 9.0);
    o_color = vec4(C(0) + C(2) * glow, 1.0);
}

Questions

Good to know.

Is Velouna really free?

Yes. Velouna is open source under the GPL-3.0. There is no account, no subscription and no advertising.

Where do the TV channels and radio stations come from?

From public directories: TV channels from iptv-org, program guides from epgshare01 and radio stations from Radio Browser. Velouna plays the streams that broadcasters publish and does not host any itself. Which channels work depends on the broadcaster; some are only available in their own country.

Do I need Plex, Jellyfin or Emby?

No. Media servers are optional. Velouna plays your local files, network streams, TV and radio without one. If you have a Plex, Jellyfin or Emby server, sign in and it shows up in the library.

What does Velouna connect to?

GitHub once a day to look for updates (you can turn this off). The TV and radio directories, program guides, logos and flags only when you open those pages. Your Plex, Jellyfin or Emby server if you sign in. There is no tracking.

Velour? Velouna?

Velouna was called Velour up to version 0.2.1. Same player, new name, because other players were already called Velour. On Windows and Linux the update from Velour installs Velouna in its place and keeps your settings and library. On Android, Velouna is a new app next to the old one.

Are plugins safe?

Visualizers can only draw: they get no access to your files and no network, and their scripts run in a sandbox with time and memory limits. Every repo is signed, and Velouna blocks updates from a repo whose key changes. Plugins in other people's repos are not checked by the Velouna project, so add only repos you trust.

Can I write my own visualizer?

Yes, with a GLSL shader and an optional Lua script, no compiler needed. Start with the getting started guide and the example plugins.

Which Linux distributions?

The .deb is for Pop!_OS, Ubuntu 22.04 or newer, Debian 12 and Linux Mint; the .tar.gz runs on other distributions with glibc 2.35 or newer. Both work on Wayland and X11 and bring their own mpv, FFmpeg and yt-dlp, so there is nothing else to install.

And macOS?

Not at the moment. Velouna is made for Windows, Linux and Android.
